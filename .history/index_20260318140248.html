04 — 디자인 철학

저는 시스템적 사고로 디자인합니다.

가장 임팩트 있는 디자인은 전체 생태계를 이해할 때 탄생합니다 - 사용자의 멘탈 모델, 팀의 제약, 시장 역학, 그리고 기술적 실현 가능성까지.

엄격한 사용자 리서치와 강한 심미적 감각을 결합하여, 항상 측정 가능한 결과를 위해 디자인합니다. 포트폴리오를 위한 디자인이 아닌, 실제 사람들의 실제 문제 해결을 위해 디자인합니다.

"최고의 UX는 보이지 않습니다 - 사용자는 그저 하려던 일을 완수할 뿐입니다."
01

발견

사용자 인터뷰, 행동 분석, 경쟁사 조사를 통해 사람들이 진정으로 필요로 하는 것을 파악합니다.

02

정의

조사 결과를 명확한 문제 정의, 여정 맵, 서비스 청사진으로 종합해 모든 이해관계자를 한 방향으로 정렬합니다.

03

디자인

와이어프레임부터 픽셀 완성 UI까지 빠르게 반복합니다. 모든 결정은 심미성이 아닌 근거에 기반합니다.

04

측정

출시 후 KPI를 모니터링하고 사용 데이터를 분석해 지속적으로 개선합니다. 좋은 디자인은 완성이 아닙니다.

05 — 경력

프로젝트 로그

단순한 산출물이 아닌 결과물의 기록입니다. 각 행을 클릭하면 상세 내용을 볼 수 있습니다.

프로젝트 역할 · 연도 성과

Vue3 Composition API와 Nuxt.js 기반으로 프론트엔드 아키텍처를 설계하고, Chart.js 및 지도 API를 활용한 실시간 대시보드와 발전 데이터 시각화를 구현했습니다. REST API 비동기 처리 안정화와 재사용 가능한 컴포넌트 설계까지 함께 수행했습니다.

PHP Laravel 기반 시스템에서 관리자 페이지와 사용자 대시보드의 UI/UX를 개선하고, 발전 시간 비교 및 보고서 자동화 기능을 추가했습니다. Bootstrap 레이아웃, 캘린더, 데이터 테이블 구조를 손보며 운영 편의성과 고객 대응 효율을 높였습니다.

홍보 영상 스토리보드 기획, 브랜드 홍보물 제작, Imweb 기반 홈페이지 관리, 오프라인 전시회 부스 운영까지 전담했습니다. 기술이 시장과 만나는 접점을 설계하면서 브랜드 일관성과 현장 커뮤니케이션 역량을 함께 키웠습니다.

06 — 실무 경험

프로젝트 디테일

기술 선택, 문제 정의, 실행, 그리고 배운 점까지. 실제 현장에서 수행한 경험을 STAR 구조로 정리했습니다.

01

에너지 IT 솔루션 기업

신규 플랫폼 구축

Vue3, Nuxt.js, 데이터 시각화, 비동기 통신

Vue3 Nuxt.js Chart.js SSR

태양광 모니터링 시스템 전문 기업 재직 당시, 기업의 지속 가능 경영(RE100)을 지원하기 위한 차세대 에너지 통합 관리 플랫폼을 구축했습니다.

Insight 대량 수치 데이터에서는 데이터의 가독성과 컴포넌트 설계 품질이 사용자 의사결정 속도를 좌우한다는 점을 깊이 체감했습니다.
S

RE100 지원을 위한 차세대 에너지 통합 관리 플랫폼 구축 프로젝트에 참여했습니다.

T

디자인 시안을 기반으로 프론트엔드 아키텍처를 설계하고, 실시간 발전 데이터를 직관적으로 보여 주는 대시보드와 시각화 기능을 구현해야 했습니다.

A
  • Vue3 Composition API와 Nuxt.js를 도입해 개발 생산성과 SSR 기반 성능 최적화를 함께 확보했습니다.
  • Tailwind CSS로 다양한 디바이스에 대응하는 반응형 UI를 구축하고, Chart.js와 지도 API로 전국 발전 순위, 동적 그래프, 위치 기반 데이터 렌더링을 구현했습니다.
  • REST API 비동기 처리를 안정화하고, Vee-validate와 재사용 가능한 UI 컴포넌트 설계로 폼 검증과 개발 리소스를 체계화했습니다.
R

플랫폼을 성공적으로 론칭했고, 디바이스 환경에 구애받지 않는 사용자 경험을 제공했습니다.

I

데이터 시각화는 단순한 표현이 아니라 의사결정을 돕는 구조라는 관점을 갖게 되었습니다.

02

에너지 관제 시스템

시스템 고도화 및 유지보수

PHP Laravel, 반응형 웹 개선, 운영 효율화

Laravel Bootstrap GitLab Figma

PHP 및 Laravel 기반으로 운영 중이던 기존 에너지 관제 시스템의 유지보수와 고도화를 맡아, 레거시 구조를 분석하고 사용자 흐름을 현대화했습니다.

Insight 기존 시스템의 한계를 파악하고 단계적으로 개선하는 과정에서 코드 분석력과 사용자 피드백 대응 역량을 크게 키웠습니다.
S

노후화된 관리자 페이지와 사용자 대시보드를 포함한 레거시 관제 시스템이 운영 중이었습니다.

T

UI/UX를 개선하고 발전 시간 비교, 보고서 자동화 등 신규 기능을 추가해 운영 효율을 높여야 했습니다.

A
  • Bootstrap 기반 레이아웃을 반응형으로 전면 개선하고, 캘린더와 데이터 테이블 구조를 최적화해 관리 편의성을 높였습니다.
  • 발전소 계통도 레이아웃 조정과 프로그레스 바 형태의 발전 정보 시각화 기능을 추가해 관제 직관성을 높였습니다.
  • GitLab과 Figma 코멘트를 활용해 요구사항 공유와 형상관리를 실시간으로 진행했습니다.
R

레이아웃 최적화와 보고서 시스템 개선으로 고객 문의 대응 리소스를 줄이고 관리 효율을 높였습니다.

I

레거시는 고치는 대상이 아니라 운영 맥락을 이해하며 진화시켜야 하는 시스템이라는 감각을 얻게 됐습니다.

03

푸드테크 스타트업

비즈니스 지원 및 기획

브랜드 관리, 전시회 기획, 멀티태스킹 역량

브랜드 전시 운영 Imweb 콘텐츠 기획

3D 푸드 프린팅 솔루션 기업에서 브랜드 가치 제고와 대외 홍보를 위한 통합 마케팅 지원 업무를 맡아 기술과 시장 사이의 접점을 설계했습니다.

Insight 기술이 시장에 전달되기까지의 전체 흐름을 경험하면서, 개발 외적 커뮤니케이션과 협업의 유연성이 얼마나 중요한지 배웠습니다.
S

자사 기술력을 시장에 알리고 브랜드 가치를 높이기 위한 마케팅 지원 체계가 필요했습니다.

T

국내외 전시회 운영 준비와 온·오프라인 홍보 콘텐츠 기획 및 관리를 전담해야 했습니다.

A
  • 홍보 영상 스토리보드를 기획하고 제작사와 커뮤니케이션했으며, 팜플렛과 PPT 등 브랜드 아이덴티티가 담긴 홍보물을 제작했습니다.
  • Imweb 기반 공식 홈페이지를 운영하며 실시간 기술 자료와 콘텐츠를 업데이트했습니다.
  • 오프라인 전시회 부스를 직접 기획·운영하며 잠재 고객의 니즈를 파악하고 브랜드 노출을 극대화했습니다.
R

일관된 브랜드 이미지 구축과 성공적인 전시 참여를 통해 솔루션 인지도를 높였습니다.

I

제품 자체뿐 아니라 그것이 전달되는 맥락까지 설계해야 진짜 비즈니스 임팩트가 난다는 관점을 갖게 됐습니다.
